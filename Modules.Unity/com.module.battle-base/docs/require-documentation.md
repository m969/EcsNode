# （战斗基地）模块需求文档

## 1. 概述
战斗基地是玩家在战斗中的核心载体，当前版本设定为**战舰**。它承载了玩家的战斗能力、生存能力以及资源管理。

## 2. 核心属性

### 2.1 品级 (Quality)
战斗基地分为五个品级，品级决定了基地的基础属性成长率和可装备部件的最高品质。
*   **下品 (Common)**
*   **中品 (Uncommon)**
*   **上品 (Rare)**
*   **极品 (Epic)**
*   **仙品 (Legendary)**

### 2.2 级别 (Level/Unlock Tier)
战斗基地拥有解锁级别，共五级（一级至五级）。
*   **作用**：
    *   主要提升**能量储存上限**。

## 3. 部件系统 (Components)
战斗基地通过装备不同类型的部件来获得战斗能力。
*   **装备限制**：部件的品级不能高于战斗基地的品级（例如：下品战舰无法装备上品武器）。
*   **部件类型**：
    *   **武器 (Weapon)**：消耗能量造成伤害。
    *   **护盾 (Shield)**：消耗能量抵挡伤害，提供护盾值。
    *   **引擎 (Engine)**：消耗能量提供移动速度或闪避率。

能量是战斗基地运作的核心资源。

## 5. 升级与成长
*   玩家可以通过消耗特定资源提升战斗基地的解锁级别。
*   升级后立即获得更高的能量上限。
