# （普攻）模块需求文档

## 功能需求列表

1. 普攻触发接口
   - 模块提供一个统一的触发接口，接收至少以下参数：攻击者ID、目标ID、当前时间戳、攻击配置ID。接口应返回操作是否被接受（布尔）。

2. 攻击分段与时序
   - 每次普攻具有明确的阶段：准备（windup）、判定（active）、收招（recovery）。每个阶段由可配置的持续时长表示。模块必须在这些阶段内按时切换状态并对外暴露当前阶段。

3. 命中判定与范围类型
   - 支持命中判定模式：单体目标(target-id)

4. 命中事件与回调
   - 当攻击命中时，模块发出命中事件，事件载荷至少包含：攻击者ID、被击者ID、造成的最终伤害值。

5. 伤害计算输入与输出
   - 模块负责将基础伤害值与影响因子组合并输出最终数值。输出必须为确定性的数值或明确的失败原因。

15. 事件钩子与监听
	- 提供一组清晰的事件钩子供外部订阅：至少包含 OnAttackStart、OnAttackHit、OnAttackCancel/Interrupt、OnAttackEnd。钩子传递的载荷必须包含足够上下文以供听众决策。

16. 输入校验与异常反馈
	- 对外部调用的输入进行必要校验（例如攻击者或目标不存在、参数越界），并以统一错误码或布尔结果反馈调用方，避免静默失败。
