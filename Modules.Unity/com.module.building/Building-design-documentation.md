# SLG游戏建筑建造功能设计文档

---
**文档说明：**
本设计文档在需求文档基础上，归纳总结建筑建造模块的功能、实体、组件和系统设计，便于后续开发和维护。
---

## 1. 模块功能概述
实现SLG游戏建筑的放置、升级、拆除等功能，支持多种建筑类型、资源消耗、建筑效果。

## 2. 模块相关实体功能设计
- 建筑实体（BuildingEntity）：
  - 记录建筑类型、等级、位置、状态、所属玩家等信息
  - 支持创建、升级、拆除等操作

## 3. 模块相关组件功能设计
- 建筑状态组件（BuildingStateComponent）：
  - 记录建造、升级、拆除等状态及剩余时间
- 建筑效果组件（BuildingEffectComponent）：
  - 记录建筑对资源、人口、防御等的加成效果
- 资源消耗组件（BuildingCostComponent）：
  - 记录建造或升级所需资源类型及数量

## 4. 模块系统功能设计
- 建筑系统（BuildingSystem）：
  - 作为建筑实体的通用系统入口，负责调度和管理建筑相关的通用逻辑
  - 支持建筑的生命周期管理（创建、激活、禁用、销毁等）
  - 可扩展通用建筑业务逻辑接口，统一调度其他建筑相关系统

- 建筑建造系统（BuildingConstructionSystem）：
  - 处理建筑的建造、升级、拆除流程
  - 管理建造队列，校验建造条件
- 建筑状态系统（BuildingStateSystem）：
  - 定时更新建筑状态，处理建造完成、升级完成等事件
- 建筑效果系统（BuildingEffectSystem）：
  - 根据建筑属性动态调整资源产出、人口上限等
- 建筑交互系统（BuildingInteractionSystem）：
  - 处理玩家与建筑的交互，如点击、移动、放置等
