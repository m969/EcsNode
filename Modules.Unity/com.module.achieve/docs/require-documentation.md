## 1. 系统概述
达成系统用于定义可完成的目标与条件，跟踪玩家完成进度，并管理达成项的状态（未开始/进行中/已完成）。本模块不包含任何奖励逻辑。

## 2. 系统功能
### 2.1 目标与条件
- 条件配置：
  - 数值型条件（如：收集N个道具、完成N次关卡）。
  - 支持多条件组合，默认“全部满足”判定为完成。
- 目标元数据：名称、描述、优先级、是否可重复（AchieveType：一次性/可重复）。

### 2.2 进度追踪
- 实时/按需更新条件当前值（由业务事件驱动或手动调用系统接口）。
- 聚合计算目标当前进度、总进度与进度百分比。

### 2.3 状态管理
- 状态：未开始/进行中/已完成。
- 完成判定：当目标内所有条件均满足时，目标状态置为“已完成”。
- 可重复目标：在满足业务规则时可重置进度并再次完成。

## 3. 边界（不做）
- 不包含奖励配置、发放、领奖与相关状态管理。
- 不与货币/道具/背包等经济系统产生耦合。

## 4. 对外扩展
- 事件：目标完成事件（如 IOnAchieveCompleted）便于外部订阅后执行奖励或其他业务逻辑。

## 5. 依赖
- 无强制依赖；建议与日志、行为统计等模块协作（可选）。
