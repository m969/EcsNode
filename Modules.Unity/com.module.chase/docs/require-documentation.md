# （追踪）模块需求文档

## 功能需求列表

2. 追踪启动/停止控制：提供开始、暂停、恢复、停止追踪的接口；可设置启动条件与停止条件（如离开范围、对象失效）。
3. 追踪范围与阈值：可配置进入/退出半径、保持距离、丢失距离；进入/退出时分别触发回调。
8. 多对象管理：支持对象列表维护、优先级规则、对象失效淘汰；在对象失效时自动重选。
9. 事件与回调：在开始追踪、对象变更、进入半径、达到保持距离、丢失对象、停止追踪等时派发事件。
10. 区域限制：支持限定追踪活动区域（如多边形/圆形）；越界时执行回退或停止策略。
13. 状态暴露：对外暴露当前追踪状态（空闲/搜索/追随/拦截/丢失）与关键数据（当前对象、距离、速度向量）。
